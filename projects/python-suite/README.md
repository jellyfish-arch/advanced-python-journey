# 🛠️ Python Advanced Utility Suite

A comprehensive collection of advanced Python projects and utilities, organized by domain. These projects demonstrate advanced concepts such as multi-threading, cryptography, computer vision, and system automation.

## 📂 Project Structure

### 🤖 Automation
- **01_file_organizer.py**: Automated file classification and directory management.
- **02_bulk_renamer.py**: Pattern-based mass file renaming utility.

### 🛡️ Security
- **01_password_vault.py**: Secure credential storage using PBKDF2 and Fernet encryption.
- **02_meta_stripper.py**: Privacy tool for removing EXIF metadata from images.

### ⚙️ System
- **01_sys_monitor.py**: Real-time hardware resource monitoring (CPU, RAM, Disk).

### 🎨 Multimedia
- **01_text_to_speech.py**: Text-to-Audio conversion engine.
- **02_hand_tracking.py**: Real-time hand gesture recognition using MediaPipe.

### 🧰 Utilities
- **01_expense_tracker.py**: CSV-based financial management system.
- **02_md_to_html.py**: Markdown parsing and HTML generation engine.
- **03_url_shortener.py**: Local URL mapping and persistence service.
- **04_notifier.py**: Cross-platform desktop notification system.
