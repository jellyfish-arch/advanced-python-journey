# 📚 Advanced Python Libraries

A collection of 10 programs demonstrating the power of essential Python libraries for real-world engineering, data science, and automation.

---

## 🛠️ Programs Overview

| File | Library | Description |
|:-----|:--------|:------------|
| `01_requests_api.py` | `requests` | API communication, JSON parsing, and HTTP error handling. |
| `02_numpy_arrays.py` | `numpy` | Scientific computing, vectorization, and matrix operations. |
| `03_pandas_data.py` | `pandas` | Data analysis, CSV processing, filtering, and aggregation. |
| `04_matplotlib_plots.py` | `matplotlib` | Creating professional charts and data visualizations. |
| `05_bs4_scraper.py` | `bs4` | Web scraping and HTML parsing from live websites. |
| `06_pillow_images.py` | `Pillow` | Image manipulation (resize, filters, rotation). |
| `07_tqdm_progress.py` | `tqdm` | Interactive progress bars for long-running scripts. |
| `08_rich_console.py` | `rich` | Beautiful terminal UIs with tables, panels, and styled text. |
| `09_pydantic_models.py` | `pydantic` | Robust data validation and type enforcement. |
| `10_dotenv_config.py` | `os / dotenv` | Environment variable management and secure configurations. |

---

## 🚀 How to Use

1. Ensure you have the required libraries installed:
   ```bash
   pip install requests numpy pandas matplotlib beautifulsoup4 pillow tqdm rich pydantic
   ```
2. Run any script to see it in action:
   ```bash
   python 01_requests_api.py
   ```
